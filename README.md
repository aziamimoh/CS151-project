# Restaurant Simulator

Restaurant Simulator is a Java application developed for our CS 151 Object-Oriented Analysis and Design group project. The application simulates basic restaurant management tasks through a JavaFX graphical user interface.

## Features

- Manage restaurant inventory and stock quantities
- Search and view inventory items
- Identify low-stock items
- Manage employees and tasks
- Assign and track employee tasks
- JavaFX-based graphical user interface

## Design

The project uses object-oriented design principles such as encapsulation, abstraction, high cohesion, and separation of responsibilities. Design patterns are also used where appropriate, including the Iterator Pattern for inventory traversal.
